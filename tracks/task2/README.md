# Track: Task 2 - a new purpose for the device (Teammate D)

A handheld that sees through materials with radar and knows exactly where each
glimpse was taken. Who would carry it?

## Candidate domains (starting list, cut to one)

| Domain | Idea | Why pose matters |
|---|---|---|
| Construction / infrastructure | Find rebar, pipes, cables, moisture behind walls; map them in 3D | Mapping hidden objects onto the real wall |
| Materials testing | Delamination and voids in composites (wind blades, aircraft panels) | Building a defect map from sweeps |
| Rescue | Locate people or voids under rubble or through smoke | Combine glimpses from a moving rescuer |
| Medicine | Wound/burn assessment through bandages, non-ionizing imaging | Repeatable scan paths, change over time |
| Logistics / customs | Inspect parcels and containers without opening | Scan large objects patch by patch |
| Agriculture / food | Foreign bodies, ripeness, moisture | Mapping a crate or pallet |

## Scoring each idea

- Who pays and how often? Is there a current tool that is worse?
- Does it need *mobility* (otherwise a fixed scanner wins)?
- Does Task 1 (pose) make it possible or just nicer? Prefer "possible".
- Regulation and privacy (radar through clothing is sensitive).
- Can we show it in a demo with what we have?

## Deliverables

- One-pagers for the top 3 (H10), mentor feedback.
- Chosen story with user flow mock and numbers (H22).
- Pitch section and demo script (H30).
